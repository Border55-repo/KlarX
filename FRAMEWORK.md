# Julian Project Framework

Dette prosjektet er opprettet fra Julian Project Framework 1.2.0 med måltypen `web`.

## Prosjektregler

- `main` skal alltid være byggbar, og endringer gjøres via branch og pull request.
- Releaser følger SemVer med oppdatert endringslogg.
- Tester, validering og bygg kjører i CI.
- Brukerdata lagres lokalt med mindre annet er uttrykkelig avtalt.
- Appen har en klikkbar statussjekk for lagring, nettverk og appressurser.
- Hemmeligheter og private brukerdata skal aldri committes.

## Ferdigdefinisjon

En endring er ferdig når appen virker, tester og bygg er grønne, dokumentasjonen er oppdatert, og endringsloggen beskriver det som faktisk er levert.
